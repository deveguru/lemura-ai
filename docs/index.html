📘 مستندات وب‌سرویس لمورا (Lemura AI Gateway)

API کاملاً سازگار با OpenAI SDK — چت، تصویر، صوت، ویدیو، جستجوی وب و Embedding با یک کلید و پرداخت تومانی.

https://lemura.ir/wp-json/lemuraai/v1

معرفی وب‌سرویس لمورا

وب‌سرویس لمورا یک درگاه یکپارچه و سازگار با OpenAI است که با یک کلید، به صدها مدل هوش مصنوعی از OpenAI، Anthropic، Google، DeepSeek، xAI، Meta، Qwen و ... دسترسی می‌دهد. هزینه هر درخواست به تومان محاسبه و از کیف پول شما کسر می‌شود.

ویژگی‌ها

  • سازگار با کتابخانه‌های رسمی OpenAI (Python، Node.js و ...) — فقط base_url را عوض کنید.
  • چت با پشتیبانی کامل از Streaming (SSE)، تصویر ورودی (Vision) و Function Calling.
  • تولید و ویرایش تصویر، تبدیل متن به گفتار، گفتار به متن، تولید ویدیو، Embedding و Moderation.
  • ورودی تصویر و PDF در چت (بینایی)، Files API، OCR اسناد و استخراج فیلدهای ساختاریافته.
  • جستجوی وب، استخراج محتوای صفحات و تحقیق خودکار.
  • پرداخت ریالی از کیف پول، بدون نیاز به کارت ارزی.

Base URL

texthttps://lemura.ir/wp-json/lemuraai/v1

آدرس جایگزین (معادل): https://lemura.ir/api/lemuraai/v1

شروع در سه قدم

  1. کیف پول خود را شارژ کنید.
  2. از صفحه توسعه‌دهندگان یک کلید API (با پیشوند lsk-) بسازید.
  3. اولین درخواست را بفرستید:
bashcurl https://lemura.ir/wp-json/lemuraai/v1/chat/completions \
  -H "Authorization: Bearer lsk-YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model": "gpt-4o-mini", "messages": [{"role": "user", "content": "سلام!"}]}'

احراز هویت

همه درخواست‌ها (به‌جز /ping) باید کلید API را در هدر Authorization ارسال کنند:

httpAuthorization: Bearer lsk-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
⚠️ کلید API را هرگز در کد سمت کاربر (مرورگر یا اپ موبایل منتشرشده) قرار ندهید. درخواست‌ها را از سرور خود ارسال کنید.

چت (Chat Completions)

/chat/completionsPOST

دقیقاً مطابق OpenAI. پارامترهای اصلی:

  • model (الزامی) — شناسه مدل، مثل gpt-4o، claude-sonnet-4-5، gemini-2.5-flash، deepseek-chat.
  • messages (الزامی) — آرایه پیام‌ها با نقش‌های system، user، assistant، tool.
  • stream — با true پاسخ به‌صورت SSE ارسال می‌شود.
  • temperature، max_tokens، max_completion_tokens، top_p، stop، tools، tool_choice، response_format، seed، reasoning_effort و n.

درخواست ساده

bashcurl https://lemura.ir/wp-json/lemuraai/v1/chat/completions \
  -H "Authorization: Bearer lsk-YOUR_KEY" -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-4o-mini",
    "messages": [
      {"role": "system", "content": "تو یک دستیار مفید فارسی‌زبان هستی."},
      {"role": "user", "content": "سه نکته برای تمرکز بیشتر بگو"}
    ],
    "temperature": 0.7
  }'

پاسخ

json{
  "id": "chatcmpl-...",
  "object": "chat.completion",
  "model": "gpt-4o-mini",
  "choices": [{"index": 0, "message": {"role": "assistant", "content": "..."}, "finish_reason": "stop"}],
  "usage": {"prompt_tokens": 32, "completion_tokens": 120, "total_tokens": 152}
}

هزینه بر اساس usage محاسبه و از کیف پول کسر می‌شود. موجودی و هزینه‌ها را با /balance و /usage ببینید. هدرهای X-RateLimit-Limit، X-RateLimit-Remaining و X-RateLimit-Reset وضعیت محدودیت نرخ را نشان می‌دهند.

Streaming

pythonstream = client.chat.completions.create(
    model="gpt-4o-mini", stream=True,
    messages=[{"role": "user", "content": "یک داستان کوتاه بنویس"}])
for chunk in stream:
    print(chunk.choices[0].delta.content or "", end="", flush=True)

تولید تصویر

/images/generationsPOST
  • model (الزامی) — مثل gpt-image-1، imagen-4.0-generate-001، flux-1.1-pro. فهرست کامل در /models.
  • prompt (الزامی، حداکثر ۱۰۰۰ کاراکتر) — توصیف تصویر. برای کیفیت بهتر انگلیسی بنویسید.
  • size — مثل 1024x1024، 1024x1792، 1792x1024.
  • n — تعداد تصاویر (هزینه × n).
  • اختیاری: quality، style، background، output_format، response_format (url یا b64_json).
bashcurl https://lemura.ir/wp-json/lemuraai/v1/images/generations \
  -H "Authorization: Bearer lsk-YOUR_KEY" -H "Content-Type: application/json" \
  -d '{"model": "gpt-image-1", "prompt": "a cozy reading nook with warm light, watercolor", "size": "1024x1024"}'
pythonimg = client.images.generate(model="gpt-image-1", prompt="a futuristic Tehran skyline at night", size="1792x1024")
print(img.data[0].url or "base64 length: %d" % len(img.data[0].b64_json))

کلیدها و قیمت‌گذاری

مدیریت کلید

  • کلیدها از صفحه توسعه‌دهندگان ساخته، غیرفعال یا حذف می‌شوند.
  • برای هر برنامه یک کلید جدا بسازید تا مصرف را جدا ببینید و در صورت لو رفتن فقط همان را حذف کنید.
  • حداکثر تعداد کلید برای هر کاربر: ۱۰.

نحوه محاسبه هزینه

  • مدل‌های متنی: بر اساس توکن ورودی، خروجی و ورودی کش‌شده، با قیمت تومانی هر مدل (در /models).
  • تصویر: قیمت ثابت به ازای هر تصویر.
  • ویدیو: قیمت هر ثانیه × مدت ویدیو.
  • صوت: قیمت ثابت به ازای هر درخواست.
  • جستجوی وب: بر اساس search_context_size.

قیمت‌ها بر اساس نرخ روز دلار محاسبه می‌شوند و ممکن است تغییر کنند. درخواست‌های ناموفق هزینه‌ای ندارند.

خطاها و رفع اشکال

خطاها در قالب استاندارد OpenAI برمی‌گردند:

json{"error": {"message": "Insufficient balance. Available: 120 toman", "type": "insufficient_balance", "code": 402}}
کدنوععلت و راه‌حل
400invalid_request_errorبدنه نامعتبر یا فیلد الزامی (مثل model، messages) ارسال نشده.
401authentication_errorکلید ارسال نشده، اشتباه است یا غیرفعال شده. هدر Authorization: Bearer lsk-... را بررسی کنید.
402insufficient_balanceموجودی کافی نیست؛ کیف پول را شارژ کنید.
404model_not_foundشناسه مدل اشتباه یا غیرفعال است؛ از /models استفاده کنید.
429rate_limit_errorعبور از محدودیت نرخ؛ به مقدار هدر Retry-After صبر کنید.
5xxserver_error / upstreamخطای موقت ارائه‌دهنده مدل؛ با تأخیر دوباره تلاش کنید. هزینه‌ای کسر نمی‌شود.

نکات

  • اگر کتابخانه OpenAI خطای اتصال می‌دهد، مطمئن شوید base_url دقیقاً https://lemura.ir/wp-json/lemuraai/v1 است (بدون /chat/completions).
  • برای درخواست‌های طولانی (تصویر و ویدیو) timeout کلاینت را حداقل ۱۸۰ ثانیه بگذارید.
  • در صورت تکرار خطای 5xx، مدل جایگزین را امتحان کنید.

    {"type": "text", "text": "متن و اعداد این رسید را استخراج کن"},
    {"type": "image_url", "image_url": {"url": "data:image/jpeg;base64,/9j/4AAQ...", "detail": "high"}}

پارامتر detail: low (سریع و ارزان)، high (متن ریز، نمودار و اسکرین‌شات)، auto. برای چند تصویر، چند بخش image_url بفرستید و در متن برچسب بزنید («تصویر A»، «تصویر B»). مدل‌های Gemini فقط ورودی Base64 را می‌پذیرند.

فایل‌ها (Files API)

یک بار آپلود کنید و بارها با file_id در چت، Responses، OCR و ویرایش تصویر استفاده کنید. ذخیره‌سازی فایل هزینه‌ای ندارد؛ فقط پردازش آن در مدل حساب می‌شود.

/filesPOST

multipart/form-data با فیلدهای file (حداکثر ۱۲۸ مگابایت) و purpose: user_data (پیشنهادی برای ورودی مدل)، vision، assistants، batch، fine-tune، evals، others. اختیاری: expires_after[anchor]=created_at و expires_after[seconds].

تشخیص متن (OCR)

/ocrPOST

استخراج ساختاریافته متن، جدول و تصاویر از PDF و تصویر با mistral-ocr-4-0 (۱۷۰ زبان، خروجی Markdown). هزینه بر اساس تعداد صفحه: حدود ۱,۲۷۰ تومان برای هر صفحه (با حاشیه‌نویسی ساختاریافته ۲٫۲۵ برابر).

  • document (الزامی): {"type": "document_url", "document_url": "https://... یا data:application/pdf;base64,..."} یا {"type": "image_url", "image_url": "..."}
  • اختیاری: pages (آرایه شماره صفحه از ۰)، include_image_base64، image_limit، image_min_size، table_format (markdown/html)، extract_header، extract_footer، document_annotation_format و bbox_annotation_format (خروجی JSON Schema).

       "document": {"type": "document_url", "document_url": "https://arxiv.org/pdf/2201.04234"},
       "pages": [0, 1], "table_format": "html"}'

استخراج فیلد (Extraction)

/extractionPOST

متن یا تصویر را بخوانید و مقدارهای نام‌دار و نوع‌دار برگردانید (شناسه، تاریخ، مبلغ، فهرست، برآورد، پیش‌بینی) — همراه با نشانه‌های عدم قطعیت. مدل: cf.clairic. هزینه بر اساس توکن ورودی (بسیار کم). پاسخ جریانی پشتیبانی نمی‌شود.

  • state: متن شواهد (یا images: تا ۴ تصویر Base64 با content_type).
  • fields: شیء نام‌دار؛ نوع‌ها: text، number، date، time، datetime، duration، list (با items)، estimate و forecast (با min/max). تنظیمات: instructions، unit، decimals، null_threshold و ...
  • اختیاری: reference_date (برای تاریخ‌های بدون سال)، options.include_quantiles، options.return_state_text.
