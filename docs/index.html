نحوهٔ درخواست

  • بدنهٔ درخواست‌ها JSON است با هدر Content-Type: application/json.

معرفی وب‌سرویس لمورا

وب‌سرویس لمورا یک درگاه یکپارچه و سازگار با OpenAI است که با یک کلید، به صدها مدل هوش مصنوعی از OpenAI، Anthropic، Google، DeepSeek، xAI، Meta، Qwen و ... دسترسی می‌دهد. هزینه هر درخواست به تومان محاسبه و از کیف پول شما کسر می‌شود.

ویژگی‌ها

  • سازگار با کتابخانه‌های رسمی OpenAI (Python، Node.js و ...) — فقط base_url را عوض کنید.
  • چت با پشتیبانی کامل از Streaming (SSE)، تصویر ورودی (Vision) و Function Calling.
  • تولید و ویرایش تصویر، تبدیل متن به گفتار، گفتار به متن، تولید ویدیو و انیمیشن (موتور Remotion لمورا)، Embedding و Moderation — و همهٔ ابزارهای پلتفرم در وب‌سرویس ابزارها.
  • ورودی تصویر و PDF در چت (بینایی)، Files API، OCR اسناد و استخراج فیلدهای ساختاریافته.
  • جستجوی وب، استخراج محتوای صفحات و تحقیق خودکار.
  • پرداخت ریالی از کیف پول، بدون نیاز به کارت ارزی.

چت (Chat Completions)

/chat/completionsPOST

دقیقاً مطابق OpenAI. پارامترهای اصلی:

  • model (الزامی) — شناسه مدل، مثل gpt-4o، claude-sonnet-4-5، gemini-2.5-flash، deepseek-chat.
  • messages (الزامی) — آرایه پیام‌ها با نقش‌های system، user، assistant، tool.
  • stream — با true پاسخ به‌صورت SSE ارسال می‌شود.
  • temperature، max_tokens، max_completion_tokens، top_p، stop، tools، tool_choice، response_format، seed، reasoning_effort و n.

درخواست ساده

bashcurl https://lemura.ir/wp-json/lemuraai/v1/chat/completions \
  -H "Authorization: Bearer lsk-YOUR_KEY" -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-4o-mini",
    "messages": [
      {"role": "system", "content": "تو یک دستیار مفید فارسی‌زبان هستی."},
      {"role": "user", "content": "سه نکته برای تمرکز بیشتر بگو"}
    ],
    "temperature": 0.7
  }'

پاسخ

json{
  "id": "chatcmpl-...",
  "object": "chat.completion",
  "model": "gpt-4o-mini",
  "choices": [{"index": 0, "message": {"role": "assistant", "content": "..."}, "finish_reason": "stop"}],
  "usage": {"prompt_tokens": 32, "completion_tokens": 120, "total_tokens": 152}
}

هزینه بر اساس usage محاسبه و از کیف پول کسر می‌شود. موجودی و هزینه‌ها را با /balance و /usage ببینید. هدرهای X-RateLimit-Limit، X-RateLimit-Remaining و X-RateLimit-Reset وضعیت محدودیت نرخ را نشان می‌دهند.

Completions (قدیمی)

/completionsPOST

برای سازگاری با کدهای قدیمی؛ پارامتر prompt به‌جای messages.

بینایی و فایل در چت

مدل‌های دارای قابلیت بینایی (مثل gpt-5.4، gpt-4o، claude-sonnet-4-6، gemini-2.5-flash) می‌توانند تصویر و PDF را مستقیماً در پیام بخوانند. هزینه تصویر و صفحات PDF به‌صورت توکن ورودی حساب می‌شود.

تصویر با URL یا Base64 (Chat Completions)

json{
  "model": "gpt-4o",
  "messages": [{"role": "user", "content": [
    {"type": "text", "text": "متن و اعداد این رسید را استخراج کن"},
    {"type": "image_url", "image_url": {"url": "data:image/jpeg;base64,/9j/4AAQ...", "detail": "high"}}
  ]}]
}

پارامتر detail: low (سریع و ارزان)، high (متن ریز، نمودار و اسکرین‌شات)، auto. برای چند تصویر، چند بخش image_url بفرستید و در متن برچسب بزنید («تصویر A»، «تصویر B»). مدل‌های Gemini فقط ورودی Base64 را می‌پذیرند.

PDF با Responses API

json{
  "model": "gpt-5.4",
  "input": [{"role": "user", "content": [
    {"type": "input_text", "text": "تعهدات اصلی این قرارداد را با شماره صفحه خلاصه کن"},

به‌جای file_url می‌توانید "filename" + "file_data": "data:application/pdf;base64,..." یا "file_id" فایلی که با Files API آپلود کرده‌اید را بفرستید. حجم هر فایل کمتر از ۵۰ مگابایت باشد.

کلیدها و قیمت‌گذاری

مدیریت کلید

  • کلیدها از صفحه توسعه‌دهندگان ساخته، غیرفعال یا حذف می‌شوند.
  • برای هر برنامه یک کلید جدا بسازید تا مصرف را جدا ببینید و در صورت لو رفتن فقط همان را حذف کنید.
  • حداکثر تعداد کلید برای هر کاربر: ۱۰.

نحوه محاسبه هزینه

  • مدل‌های متنی: بر اساس توکن ورودی، خروجی و ورودی کش‌شده، با قیمت تومانی هر مدل (در /models).
  • تصویر: قیمت ثابت به ازای هر تصویر.
  • ویدیو: طراحی صحنه‌ها (مثل یک پیام چت) + رندر Remotion بر اساس پردازش واقعی (همان تعرفهٔ ابزار animation_render).
  • صوت: قیمت ثابت به ازای هر درخواست.
  • جستجوی وب: بر اساس search_context_size.

قیمت‌ها بر اساس نرخ روز دلار محاسبه می‌شوند و ممکن است تغییر کنند. درخواست‌های ناموفق هزینه‌ای ندارند.

خطاها و رفع اشکال

خطاها در قالب استاندارد OpenAI برمی‌گردند:

json{"error": {"message": "Insufficient balance. Available: 120 toman", "type": "insufficient_balance", "code": 402}}
کدنوععلت و راه‌حل
400invalid_request_errorبدنه نامعتبر یا فیلد الزامی (مثل model، messages) ارسال نشده.
401authentication_errorکلید ارسال نشده، اشتباه است یا غیرفعال شده. هدر Authorization: Bearer lsk-... را بررسی کنید.
402insufficient_balanceموجودی کافی نیست؛ کیف پول را شارژ کنید.
404model_not_foundشناسه مدل اشتباه یا غیرفعال است؛ از /models استفاده کنید.
429rate_limit_errorعبور از محدودیت نرخ؛ به مقدار هدر Retry-After صبر کنید.
5xxserver_error / upstreamخطای موقت ارائه‌دهنده مدل؛ با تأخیر دوباره تلاش کنید. هزینه‌ای کسر نمی‌شود.

نکات

  • اگر کتابخانه OpenAI خطای اتصال می‌دهد، مطمئن شوید base_url دقیقاً https://lemura.ir/wp-json/lemuraai/v1 است (بدون /chat/completions).
  • برای درخواست‌های طولانی (تصویر و ویدیو) timeout کلاینت را حداقل ۱۸۰ ثانیه بگذارید.
  • در صورت تکرار خطای 5xx، مدل جایگزین را امتحان کنید.
