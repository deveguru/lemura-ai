معرفی وب‌سرویس لمورا
========================================================================

وب‌سرویس لمورا یک درگاه یکپارچه و سازگار با OpenAI است که با یک کلید، به صدها مدل هوش مصنوعی از OpenAI، Anthropic، Google، DeepSeek، xAI، Meta، Qwen و ... دسترسی می‌دهد. هزینه هر درخواست به تومان محاسبه و از کیف پول شما کسر می‌شود.

## ویژگی‌ها
  - سازگار با کتابخانه‌های رسمی OpenAI (Python، Node.js و ...) — فقط base_url را عوض کنید.
  - چت با پشتیبانی کامل از Streaming (SSE)، تصویر ورودی (Vision) و Function Calling.
  - تولید و ویرایش تصویر، تبدیل متن به گفتار، گفتار به متن، تولید ویدیو، Embedding و Moderation.
  - ورودی تصویر و PDF در چت (بینایی)، Files API، OCR اسناد و استخراج فیلدهای ساختاریافته.
  - جستجوی وب، استخراج محتوای صفحات و تحقیق خودکار.
  - پرداخت ریالی از کیف پول، بدون نیاز به کارت ارزی.

## Base URL

    https://lemura.ir/wp-json/lemuraai/v1

آدرس جایگزین (معادل): https://lemura.ir/api/lemuraai/v1

## شروع در سه قدم
  - کیف پول خود را شارژ کنید.
  - از صفحه توسعه‌دهندگان یک کلید API (با پیشوند lsk-) بسازید.
  - اولین درخواست را بفرستید:

    curl https://lemura.ir/wp-json/lemuraai/v1/chat/completions \
      -H "Authorization: Bearer lsk-YOUR_KEY" \
      -H "Content-Type: application/json" \
      -d '{"model": "gpt-4o-mini", "messages": [{"role": "user", "content": "سلام!"}]}'

چت (Chat Completions)
========================================================================

    POST /chat/completions
دقیقاً مطابق OpenAI. پارامترهای اصلی:
  - model (الزامی) — شناسه مدل، مثل gpt-4o، claude-sonnet-4-5، gemini-2.5-flash، deepseek-chat.
  - messages (الزامی) — آرایه پیام‌ها با نقش‌های system، user، assistant، tool.
  - stream — با true پاسخ به‌صورت SSE ارسال می‌شود.
  - temperature، max_tokens، max_completion_tokens، top_p، stop، tools، tool_choice، response_format، seed، reasoning_effort و n.

## درخواست ساده

    curl https://lemura.ir/wp-json/lemuraai/v1/chat/completions \
      -H "Authorization: Bearer lsk-YOUR_KEY" -H "Content-Type: application/json" \
      -d '{
        "model": "gpt-4o-mini",
        "messages": [
          {"role": "system", "content": "تو یک دستیار مفید فارسی‌زبان هستی."},
          {"role": "user", "content": "سه نکته برای تمرکز بیشتر بگو"}
        ],
        "temperature": 0.7
      }'

## پاسخ

    {
      "id": "chatcmpl-...",
      "object": "chat.completion",
      "model": "gpt-4o-mini",
      "choices": [{"index": 0, "message": {"role": "assistant", "content": "..."}, "finish_reason": "stop"}],
      "usage": {"prompt_tokens": 32, "completion_tokens": 120, "total_tokens": 152}
    }

هزینه بر اساس usage محاسبه و از کیف پول کسر می‌شود. موجودی و هزینه‌ها را با /balance و /usage ببینید. هدرهای X-RateLimit-Limit، X-RateLimit-Remaining و X-RateLimit-Reset وضعیت محدودیت نرخ را نشان می‌دهند.

## Streaming

    stream = client.chat.completions.create(
        model="gpt-4o-mini", stream=True,
        messages=[{"role": "user", "content": "یک داستان کوتاه بنویس"}])
    for chunk in stream:
        print(chunk.choices[0].delta.content or "", end="", flush=True)

## تصویر ورودی (Vision)

    {
      "model": "gpt-4o",
      "messages": [{"role": "user", "content": [
        {"type": "text", "text": "در این تصویر چه می‌بینی؟"},
        {"type": "image_url", "image_url": {"url": "https://example.com/photo.jpg"}}
      ]}]
    }

## Function Calling

    {
      "model": "gpt-4o-mini",
      "messages": [{"role": "user", "content": "هوای تهران چطوره؟"}],
      "tools": [{"type": "function", "function": {
        "name": "get_weather",
        "parameters": {"type": "object", "properties": {"city": {"type": "string"}}, "required": ["city"]}
      }}]
    }

Responses API
========================================================================

    POST /responses
رابط جدید OpenAI برای مدل‌های استدلالی و ابزارها. ورودی می‌تواند متن ساده یا آرایه‌ای از پیام‌ها باشد.

    curl https://lemura.ir/wp-json/lemuraai/v1/responses \
      -H "Authorization: Bearer lsk-YOUR_KEY" -H "Content-Type: application/json" \
      -d '{"model": "gpt-5-mini", "input": "تفاوت هوش مصنوعی و یادگیری ماشین چیست؟"}'

    r = client.responses.create(model="gpt-5-mini", input="یک شعر کوتاه درباره پاییز")
    print(r.output_text)

## Completions (قدیمی)
    POST /completions
برای سازگاری با کدهای قدیمی؛ پارامتر prompt به‌جای messages.

تولید تصویر
========================================================================

    POST /images/generations
  - model (الزامی) — مثل gpt-image-1، imagen-4.0-generate-001، flux-1.1-pro. فهرست کامل در /models.
  - prompt (الزامی، حداکثر ۱۰۰۰ کاراکتر) — توصیف تصویر. برای کیفیت بهتر انگلیسی بنویسید.
  - size — مثل 1024x1024، 1024x1792، 1792x1024.
  - n — تعداد تصاویر (هزینه × n).
  - اختیاری: quality، style، background، output_format، response_format (url یا b64_json).

    curl https://lemura.ir/wp-json/lemuraai/v1/images/generations \
      -H "Authorization: Bearer lsk-YOUR_KEY" -H "Content-Type: application/json" \
      -d '{"model": "gpt-image-1", "prompt": "a cozy reading nook with warm light, watercolor", "size": "1024x1024"}'

    img = client.images.generate(model="gpt-image-1", prompt="a futuristic Tehran skyline at night", size="1792x1024")
    print(img.data[0].url or "base64 length: %d" % len(img.data[0].b64_json))

هزینه قبل از ارسال برآورد و بررسی می‌شود؛ اگر موجودی کافی نباشد خطای 402 برمی‌گردد.

صوت
========================================================================

## متن به گفتار (TTS)
    POST /audio/speech
پارامترها: model (مثل gpt-4o-mini-tts، tts-1، tts-1-hd)، input (متن)، voice (مثل alloy، nova، shimmer، echo). خروجی فایل صوتی است. هزینه هر درخواست: حدود ۵۰۰ تومان (پیش از سود).

    curl https://lemura.ir/wp-json/lemuraai/v1/audio/speech \
      -H "Authorization: Bearer lsk-YOUR_KEY" -H "Content-Type: application/json" \
      -d '{"model": "gpt-4o-mini-tts", "input": "سلام، به لمورا خوش آمدید", "voice": "nova"}' \
      --output speech.mp3

## گفتار به متن
    POST /audio/transcriptions
ارسال به‌صورت multipart/form-data با فیلدهای file و model (مثل gpt-4o-transcribe، gpt-4o-mini-transcribe، whisper-1؛ فهرست به‌روز در /models). اختیاری: language، prompt، response_format، temperature.

    curl https://lemura.ir/wp-json/lemuraai/v1/audio/transcriptions \
      -H "Authorization: Bearer lsk-YOUR_KEY" \
      -F file=@voice.mp3 -F model=whisper-1 -F language=fa

## ترجمه گفتار به انگلیسی
    POST /audio/translations
مانند transcriptions، با مدل whisper-1؛ خروجی متن انگلیسی است.

تولید ویدیو
========================================================================

تولید ویدیو ناهمگام است: ابتدا کار را بسازید، سپس وضعیت را بررسی و در پایان فایل را دریافت کنید.
    POST /videos

    GET /videos/{video_id}/content

جستجو و تحقیق وب
========================================================================

## جستجوی وب با پاسخ هوشمند
    POST /web-search
ارسال query (یا messages) و مدل جستجو (پیش‌فرض gpt-4o-search-preview). پارامتر search_context_size: low، medium یا high (هزینه بیشتر، منابع بیشتر).

    curl https://lemura.ir/wp-json/lemuraai/v1/web-search \
      -H "Authorization: Bearer lsk-YOUR_KEY" -H "Content-Type: application/json" \
      -d '{"query": "آخرین اخبار هوش مصنوعی این هفته", "search_context_size": "medium"}'

## استخراج محتوای صفحه
    POST /web-scrape
url یا آرایه urls؛ اختیاری max_chars_per_url (۵۰۰ تا ۵۰٬۰۰۰). خروجی متن تمیزشده هر صفحه است.

    {"urls": ["https://example.com/article"], "max_chars_per_url": 8000}

## تحقیق خودکار
    POST /research
query (یا topic)؛ اختیاری model و max_results. گزارشی جمع‌بندی‌شده با منابع برمی‌گرداند.

Embedding و Moderation
========================================================================

    POST /embeddings

کلیدها و قیمت‌گذاری
========================================================================

## مدیریت کلید
  - کلیدها از صفحه توسعه‌دهندگان ساخته، غیرفعال یا حذف می‌شوند.
  - برای هر برنامه یک کلید جدا بسازید تا مصرف را جدا ببینید و در صورت لو رفتن فقط همان را حذف کنید.
  - حداکثر تعداد کلید برای هر کاربر: ۱۰.

## نحوه محاسبه هزینه
  - مدل‌های متنی: بر اساس توکن ورودی، خروجی و ورودی کش‌شده، با قیمت تومانی هر مدل (در /models).
  - تصویر: قیمت ثابت به ازای هر تصویر.
  - ویدیو: قیمت هر ثانیه × مدت ویدیو.
  - صوت: قیمت ثابت به ازای هر درخواست.
  - جستجوی وب: بر اساس search_context_size.
قیمت‌ها بر اساس نرخ روز دلار محاسبه می‌شوند و ممکن است تغییر کنند. درخواست‌های ناموفق هزینه‌ای ندارند.

## Python (کتابخانه openai)

    # pip install openai
    from openai import OpenAI

    client = OpenAI(api_key="lsk-YOUR_KEY", base_url="https://lemura.ir/wp-json/lemuraai/v1")
    resp = client.chat.completions.create(
        model="gpt-4o-mini",
        messages=[{"role": "user", "content": "یک تابع مرتب‌سازی سریع بنویس"}],
    )
    print(resp.choices[0].message.content)

## Node.js

    // npm i openai
    import OpenAI from "openai";

    const client = new OpenAI({ apiKey: process.env.LEMURA_KEY, baseURL: "https://lemura.ir/wp-json/lemuraai/v1" });
    const stream = await client.chat.completions.create({
      model: "gpt-4o-mini", stream: true,
      messages: [{ role: "user", content: "سلام!" }],
    });
    for await (const part of stream) process.stdout.write(part.choices[0]?.delta?.content || "");

## PHP

    $ch = curl_init("https://lemura.ir/wp-json/lemuraai/v1/chat/completions");

خطاها و رفع اشکال
========================================================================

خطاها در قالب استاندارد OpenAI برمی‌گردند:

    {"error": {"message": "Insufficient balance. Available: 120 toman", "type": "insufficient_balance", "code": 402}}

  کد | نوع | علت و راه‌حل
  400 | invalid_request_error | بدنه نامعتبر یا فیلد الزامی (مثل model، messages) ارسال نشده.
  401 | authentication_error | کلید ارسال نشده، اشتباه است یا غیرفعال شده. هدر Authorization: Bearer lsk-... را بررسی کنید.
  402 | insufficient_balance | موجودی کافی نیست؛ کیف پول را شارژ کنید.
  404 | model_not_found | شناسه مدل اشتباه یا غیرفعال است؛ از /models استفاده کنید.
  429 | rate_limit_error | عبور از محدودیت نرخ؛ به مقدار هدر Retry-After صبر کنید.
  5xx | server_error / upstream | خطای موقت ارائه‌دهنده مدل؛ با تأخیر دوباره تلاش کنید. هزینه‌ای کسر نمی‌شود.

## نکات
  - اگر کتابخانه OpenAI خطای اتصال می‌دهد، مطمئن شوید base_url دقیقاً https://lemura.ir/wp-json/lemuraai/v1 است (بدون /chat/completions).
  - برای درخواست‌های طولانی (تصویر و ویدیو) timeout کلاینت را حداقل ۱۸۰ ثانیه بگذارید.
  - در صورت تکرار خطای 5xx، مدل جایگزین را امتحان کنید.

## آیا با کدهای فعلی OpenAI سازگار است؟
بله. فقط api_key را با کلید لمورا و base_url را با آدرس لمورا جایگزین کنید.

خیر. فقط درخواست‌های موفق هزینه دارند.

## چطور بفهمم هر درخواست چقدر هزینه داشته؟
از /usage و /balance یا تاریخچه کیف پول استفاده کنید.

## کلیدم لو رفته، چه کنم؟
فوراً از صفحه توسعه‌دهندگان آن را حذف و کلید جدید بسازید.

بینایی و فایل در چت
========================================================================

مدل‌های دارای قابلیت بینایی (مثل gpt-5.4، gpt-4o، claude-sonnet-4-6، gemini-2.5-flash) می‌توانند تصویر و PDF را مستقیماً در پیام بخوانند. هزینه تصویر و صفحات PDF به‌صورت توکن ورودی حساب می‌شود.

## تصویر با URL یا Base64 (Chat Completions)

    {
      "model": "gpt-4o",
      "messages": [{"role": "user", "content": [
        {"type": "text", "text": "متن و اعداد این رسید را استخراج کن"},
        {"type": "image_url", "image_url": {"url": "data:image/jpeg;base64,/9j/4AAQ...", "detail": "high"}}
      ]}]
    }

پارامتر detail: low (سریع و ارزان)، high (متن ریز، نمودار و اسکرین‌شات)، auto. برای چند تصویر، چند بخش image_url بفرستید و در متن برچسب بزنید («تصویر A»، «تصویر B»). مدل‌های Gemini فقط ورودی Base64 را می‌پذیرند.

## PDF با Responses API

    {
      "model": "gpt-5.4",
      "input": [{"role": "user", "content": [
        {"type": "input_text", "text": "تعهدات اصلی این قرارداد را با شماره صفحه خلاصه کن"},
        {"type": "input_file", "file_url": "https://example.com/contract.pdf"}
      ]}]
    }

به‌جای file_url می‌توانید "filename" + "file_data": "data:application/pdf;base64,..." یا "file_id" فایلی که با Files API آپلود کرده‌اید را بفرستید. حجم هر فایل کمتر از ۵۰ مگابایت باشد.

## فایل آپلودشده در Chat Completions

    {
      "model": "gemini-2.5-flash",
      "messages": [{"role": "user", "content": [
        {"type": "text", "text": "این سند را خلاصه کن"},
        {"type": "file", "file": {"file_id": "file-EyVi0MrxuKTgBrvkVas5ZTGz"}}
      ]}]
    }

🔒 فقط به file_idهایی که با کلید حساب خودتان آپلود کرده‌اید می‌توانید ارجاع دهید؛ شناسه فایل دیگران خطای 404 می‌دهد.

========================================================================

فایل‌ها (Files API)
========================================================================

یک بار آپلود کنید و بارها با file_id در چت، Responses، OCR و ویرایش تصویر استفاده کنید. ذخیره‌سازی فایل هزینه‌ای ندارد؛ فقط پردازش آن در مدل حساب می‌شود.
    POST /files
multipart/form-data با فیلدهای file (حداکثر ۱۲۸ مگابایت) و purpose: user_data (پیشنهادی برای ورودی مدل)، vision، assistants، batch، fine-tune، evals، others. اختیاری: expires_after[anchor]=created_at و expires_after[seconds].

    curl https://lemura.ir/wp-json/lemuraai/v1/files \
      -H "Authorization: Bearer lsk-YOUR_KEY" \
      -F purpose="user_data" -F file="@contract.pdf"

    {"id": "file-EyVi0MrxuKTgBrvkVas5ZTGz", "object": "file", "bytes": 13264, "created_at": 1767210968,
     "filename": "contract.pdf", "purpose": "user_data"}

    GET /files?purpose=user_data&limit=100&order=desc
فهرست فایل‌های حساب شما.
    GET /files/{file_id}
    GET /files/{file_id}/content
    DELETE /files/{file_id}

    f = client.files.create(file=open("contract.pdf", "rb"), purpose="user_data")
    r = client.responses.create(model="gpt-5.4", input=[{"role": "user", "content": [
        {"type": "input_file", "file_id": f.id},
        {"type": "input_text", "text": "مهم‌ترین بندها را فهرست کن"}]}])
    print(r.output_text)
    client.files.delete(f.id)

تشخیص متن (OCR)
========================================================================

    POST /ocr
استخراج ساختاریافته متن، جدول و تصاویر از PDF و تصویر با mistral-ocr-4-0 (۱۷۰ زبان، خروجی Markdown). هزینه بر اساس تعداد صفحه: حدود ۱,۲۷۰ تومان برای هر صفحه (با حاشیه‌نویسی ساختاریافته ۲٫۲۵ برابر).
  - document (الزامی): {"type": "document_url", "document_url": "https://... یا data:application/pdf;base64,..."} یا {"type": "image_url", "image_url": "..."}
  - اختیاری: pages (آرایه شماره صفحه از ۰)، include_image_base64، image_limit، image_min_size، table_format (markdown/html)، extract_header، extract_footer، document_annotation_format و bbox_annotation_format (خروجی JSON Schema).

    curl https://lemura.ir/wp-json/lemuraai/v1/ocr \
      -H "Authorization: Bearer lsk-YOUR_KEY" -H "Content-Type: application/json" \
      -d '{"model": "mistral-ocr-4-0",
           "document": {"type": "document_url", "document_url": "https://arxiv.org/pdf/2201.04234"},
           "pages": [0, 1], "table_format": "html"}'

    {
      "pages": [{"index": 0, "markdown": "# عنوان سند\n\nمتن استخراج‌شده...", "dimensions": {"dpi": 200, "height": 2200, "width": 1700}, "images": []}],
      "model": "mistral-ocr-4-0",
      "usage_info": {"pages_processed": 2, "doc_size_bytes": 3002783},
      "object": "ocr"
    }

## استخراج داده ساختاریافته از فاکتور

    {
      "model": "mistral-ocr-4-0",
      "document": {"type": "document_url", "document_url": "https://example.com/invoice.pdf"},
      "document_annotation_format": {"type": "json_schema", "json_schema": {"name": "invoice", "schema": {
        "type": "object", "required": ["invoice_number", "total_amount"],
        "properties": {"invoice_number": {"type": "string"}, "date": {"type": "string"}, "total_amount": {"type": "number"}}}}}
    }

نتیجه ساختاریافته در فیلد document_annotation به‌صورت رشته JSON برمی‌گردد. پیش از ثبت مالی، مبلغ‌ها و تاریخ‌ها را با سند اصلی تطبیق دهید.

========================================================================

ویرایش تصویر
========================================================================

    POST /images/edits
ویرایش تصویر موجود با توضیح متنی (حذف پس‌زمینه، افزودن شیء، تغییر سبک...). مدل‌ها و قیمت همانند تولید تصویر است (مدل‌های فعال در /models با نوع image).

## آپلود فایل (multipart)

    curl https://lemura.ir/wp-json/lemuraai/v1/images/edits \
      -H "Authorization: Bearer lsk-YOUR_KEY" \
      -F model="gpt-image-2" -F image="@product.png" \
      -F prompt="فقط پس‌زمینه را سفید گرم کن؛ محصول، لوگو و زاویه دوربین تغییر نکند" \
      -F size="1024x1024"

## درخواست JSON با Base64

    {
      "model": "gpt-image-2",
      "prompt": "یک رنگین‌کمان در آسمان بالای کوه‌ها اضافه کن",
      "images": [{"image_url": "data:image/png;base64,iVBORw0KGgo..."}],
      "size": "1024x1024"
    }

اختیاری: mask (فایل یا {"image_url": ...} با کانال آلفا؛ ناحیه شفاف قابل ویرایش است)، n (حداکثر ۴)، quality، output_format. خروجی در data[0].b64_json یا data[0].url است. در پرامپت کل تصویر نهایی را توصیف کنید و بگویید چه چیزهایی باید بدون تغییر بمانند.

استخراج فیلد (Extraction)
========================================================================

    POST /extraction
متن یا تصویر را بخوانید و مقدارهای نام‌دار و نوع‌دار برگردانید (شناسه، تاریخ، مبلغ، فهرست، برآورد، پیش‌بینی) — همراه با نشانه‌های عدم قطعیت. مدل: cf.clairic. هزینه بر اساس توکن ورودی (بسیار کم). پاسخ جریانی پشتیبانی نمی‌شود.
  - state: متن شواهد (یا images: تا ۴ تصویر Base64 با content_type).
  - fields: شیء نام‌دار؛ نوع‌ها: text، number، date، time، datetime، duration، list (با items)، estimate و forecast (با min/max). تنظیمات: instructions، unit، decimals، null_threshold و ...
  - اختیاری: reference_date (برای تاریخ‌های بدون سال)، options.include_quantiles، options.return_state_text.

    curl https://lemura.ir/wp-json/lemuraai/v1/extraction \
      -H "Authorization: Bearer lsk-YOUR_KEY" -H "Content-Type: application/json" \
      -d '{"model": "cf.clairic",
           "state": "Invoice INV-2291 issued 2026-09-02, net 30. 4 pallets at $250.00, shipping $80.00. Contact: Dana Ruiz, Priya Shah.",
           "fields": {
             "invoice_number": {"type": "text"},
             "due_date": {"type": "date", "instructions": "Issue date plus net payment days"},
             "total": {"type": "number", "decimals": 2, "unit": "USD", "instructions": "Amount due including shipping"},
             "contacts": {"type": "list", "items": "text"},
             "po_number": {"type": "text", "instructions": "Purchase order number"}}}'

    {
      "model": "cf.clairic",
      "answers": {
        "invoice_number": {"type": "text", "value": "INV-2291", "confidence": 1, "p_null": 3.8e-10, "span": [8, 16]},
        "due_date": {"type": "date", "value": "2026-10-02"},
        "total": {"type": "number", "value": 1080},
        "contacts": {"type": "list", "value": ["Dana Ruiz", "Priya Shah"]},
        "po_number": {"type": "text", "value": null, "p_null": 1, "guess": "INV-2291"}
      },
      "truncated": false,
      "usage": {"input_tokens": 655, "output_tokens": 0, "passes": 3}
    }

⚠️ value: null یعنی مقدار پیدا نشد؛ guess را جایگزین آن نکنید (در مثال، شماره سفارش خرید وجود ندارد). پیش از ذخیره یا اقدام، مقدارها را اعتبارسنجی کنید.

گفتگوی صوتی زنده
========================================================================

برای ساخت دستیار صوتی، سه مرحله را زنجیره کنید: گفتار به متن ← چت ← متن به گفتار. این همان روشی است که «گفتگوی صوتی» سایت لمورا استفاده می‌کند.

    with open("question.webm", "rb") as audio:
        text = client.audio.transcriptions.create(model="gpt-4o-transcribe", file=audio, language="fa").text

    answer = client.chat.completions.create(model="gpt-5.4-mini", messages=[
        {"role": "system", "content": "کوتاه و محاوره‌ای پاسخ بده."},
        {"role": "user", "content": text}]).choices[0].message.content

    with client.audio.speech.with_streaming_response.create(
            model="gpt-audio-1.5", voice="coral", input=answer, response_format="mp3") as speech:
        speech.stream_to_file("answer.mp3")

  - متن هر درخواست TTS را زیر ۴٬۰۰۰ کاراکتر نگه دارید؛ متن طولانی را پاراگراف به پاراگراف بفرستید.
  - صداهای پیشنهادی: coral، marin، cedar، alloy، nova.
  - برای کاهش تأخیر، پاسخ چت را کوتاه بخواهید و پخش را هم‌زمان با دریافت فایل شروع کنید.
  - به کاربر اطلاع دهید که صدای پاسخ با هوش مصنوعی تولید شده است.
