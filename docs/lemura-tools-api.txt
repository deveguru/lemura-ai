Base URL: `https://lemura.ir/public/v1` · [OpenAPI JSON](openapi-tools.json)

## قواعد مشترک هر دو وب‌سرویس

### احراز هویت

هر دو وب‌سرویس با یک کلید کار می‌کنند. کلید را در صفحهٔ «کلیدها و آمار» بسازید و در هدر هر درخواست بفرستید:

```bash
Authorization: Bearer lsk-YOUR_KEY
```

### نحوهٔ درخواست

- بدنهٔ درخواست‌ها JSON است با هدر `Content-Type: application/json`.
- ارسال فایل با `multipart/form-data` (فیلد فایل؛ در ابزارها هم‌نام پارامتر و آرگومان‌های دیگر در فیلد args به‌صورت JSON).
- پاسخ‌ها همیشه JSON با کدگذاری UTF-8 است؛ مبالغ به تومان است.
- کارهای طولانی (ویدیو، OCR، تبدیل صوت و...) ناهمگام هستند: شناسهٔ کار برمی‌گردد و وضعیت را بعداً می‌پرسید.

### متدها

| متد | کاربرد |
|---|---|
| GET | خواندن: فهرست مدل‌ها/ابزارها، موجودی، وضعیت کار، دریافت فایل |
| POST | اجرا: چت، تولید تصویر/ویدیو، فراخوانی ابزار، آپلود فایل، ساخت وظیفه |
| DELETE | حذف: فایل، ویدیو، وظیفه |

### موجودی کیف پول و اطلاعات حساب

موجودی و اطلاعات حساب از هر دو وب‌سرویس با پاسخ یکسان در دسترس است:

```bash
GET https://lemura.ir/wp-json/lemuraai/v1/balance
GET https://lemura.ir/public/v1/balance

GET https://lemura.ir/wp-json/lemuraai/v1/me
GET https://lemura.ir/public/v1/me
```

```bash
curl https://lemura.ir/public/v1/balance -H "Authorization: Bearer lsk-YOUR_KEY"

{"object": "balance", "user_id": 42, "balance": 125000, "currency": "toman", ...}
```

### کدهای خطا

| HTTP | معنی |
|---|---|
| 400 | ورودی نامعتبر |
| 401 | کلید ارسال نشده یا نامعتبر است |
| 402 | موجودی کیف پول کافی نیست |
| 403 | دسترسی به این مدل/ابزار مجاز نیست |
| 404 | مدل، ابزار یا کار پیدا نشد |
| 409 / 428 | کار هنوز آماده نیست / عملیات تغییردهنده نیاز به هدر X-Lemura-Confirm: true دارد |
| 429 | عبور از سقف تعداد درخواست یا سهمیهٔ روزانه (هدرهای X-RateLimit-*) |
| 5xx | خطای موقت سرور یا سرویس بالادستی — چند ثانیه بعد دوباره تلاش کنید |

### شروع سریع

آدرس پایه: `https://lemura.ir/public/v1` — احراز هویت با هدر `Authorization: Bearer lsk-...` — قیمت‌ها برای پلن «رایگان»

```
# ساخت پاورپوینت
curl -X POST https://lemura.ir/public/v1/tools/pptx_generate \
  -H "Authorization: Bearer lsk-YOUR_KEY" -H "Content-Type: application/json" \
  -d '{"title":"گزارش فصلی","slides":[{"title":"خلاصه","bullets":["رشد ۲۰٪","۳ محصول جدید"]}]}'

# ارسال فایل (multipart): فیلد فایل هم‌نام پارامتر ابزار است
curl -X POST "https://lemura.ir/public/v1/tools/ocr_image?wait=30" -H "Authorization: Bearer lsk-YOUR_KEY" \
  -F file=@scan.jpg -F 'args={"languages":["fa","en"]}'

# کارهای طولانی job_id برمی‌گردانند (HTTP 202)
curl https://lemura.ir/public/v1/jobs/job_xxx -H "Authorization: Bearer lsk-YOUR_KEY"
```

**خروجی یکسان**

`{ ok, data, files[], error, meta }` — فایل‌ها با لینک دانلود موقت

**هزینه**

پایه + وزن پردازش × واحد پردازش واقعی؛ مبلغ دقیق در meta.cost

**خطاها**

400 ورودی · 401 کلید · 402 موجودی · 403 دسترسی · 428 تأیید · 429 سقف
