تولید تصویر

{{ ep('POST','/images/generations') }}
  • model (الزامی) — مثل gpt-image-1، imagen-4.0-generate-001، flux-1.1-pro. فهرست کامل در /models.
  • prompt (الزامی، حداکثر ۱۰۰۰ کاراکتر) — توصیف تصویر. برای کیفیت بهتر انگلیسی بنویسید.
  • size — مثل 1024x1024، 1024x1792، 1792x1024.
  • n — تعداد تصاویر (هزینه × n).
  • اختیاری: quality، style، background، output_format، response_format (url یا b64_json).

تولید ویدیو

تولید ویدیو ناهمگام است: ابتدا کار را بسازید، سپس وضعیت را بررسی و در پایان فایل را دریافت کنید.

{{ ep('POST','/videos') }}

پارامترها: model (sora-2، sora-2-pro، veo-3.1-generate-001، veo-3.1-fast-generate-001، ...)، prompt، seconds (یا duration) و size. هزینه = قیمت هر ثانیه × مدت.

{% call code('bash') %}curl {{ B }}/videos \ -H "Authorization: Bearer lsk-YOUR_KEY" -H "Content-Type: application/json" \ -d '{"model": "sora-2", "prompt": "a paper boat drifting on a rainy street, cinematic", "seconds": 8}'{% endcall %} {{ ep('GET','/videos/{video_id}') }}
