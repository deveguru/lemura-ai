بینایی و فایل در چت

مدل‌های دارای قابلیت بینایی (مثل gpt-5.4، gpt-4o، claude-sonnet-4-6، gemini-2.5-flash) می‌توانند تصویر و PDF را مستقیماً در پیام بخوانند. هزینه تصویر و صفحات PDF به‌صورت توکن ورودی حساب می‌شود.

تصویر با URL یا Base64 (Chat Completions)

{% call code('json') %}{ "model": "gpt-4o", "messages": [{"role": "user", "content": [ {"type": "text", "text": "متن و اعداد این رسید را استخراج کن"}, {"type": "image_url", "image_url": {"url": "data:image/jpeg;base64,/9j/4AAQ...", "detail": "high"}} ]}] }{% endcall %}

پارامتر detail: low (سریع و ارزان)، high (متن ریز، نمودار و اسکرین‌شات)، auto. برای چند تصویر، چند بخش image_url بفرستید و در متن برچسب بزنید («تصویر A»، «تصویر B»). مدل‌های Gemini فقط ورودی Base64 را می‌پذیرند.

PDF با Responses API

{% call code('json') %}{ "model": "gpt-5.4", "input": [{"role": "user", "content": [ {"type": "input_text", "text": "تعهدات اصلی این قرارداد را با شماره صفحه خلاصه کن"}, {"type": "input_file", "file_url": "https://example.com/contract.pdf"} ]}] }{% endcall %}

به‌جای file_url می‌توانید "filename" + "file_data": "data:application/pdf;base64,..." یا "file_id" فایلی که با Files API آپلود کرده‌اید را بفرستید. حجم هر فایل کمتر از ۵۰ مگابایت باشد.

فایل آپلودشده در Chat Completions

{% call code('json') %}{ "model": "gemini-2.5-flash", "messages": [{"role": "user", "content": [ {"type": "text", "text": "این سند را خلاصه کن"}, {"type": "file", "file": {"file_id": "file-EyVi0MrxuKTgBrvkVas5ZTGz"}} ]}] }{% endcall %}
🔒 فقط به file_idهایی که با کلید حساب خودتان آپلود کرده‌اید می‌توانید ارجاع دهید؛ شناسه فایل دیگران خطای 404 می‌دهد.

فایل‌ها (Files API)

یک بار آپلود کنید و بارها با file_id در چت، Responses، OCR و ویرایش تصویر استفاده کنید. ذخیره‌سازی فایل هزینه‌ای ندارد؛ فقط پردازش آن در مدل حساب می‌شود.

{{ ep('POST','/files') }}

multipart/form-data با فیلدهای file (حداکثر ۱۲۸ مگابایت) و purpose: user_data (پیشنهادی برای ورودی مدل)، vision، assistants، batch، fine-tune، evals، others. اختیاری: expires_after[anchor]=created_at و expires_after[seconds].

{% call code('bash') %}curl {{ B }}/files \ -H "Authorization: Bearer lsk-YOUR_KEY" \ -F purpose="user_data" -F file="@contract.pdf"{% endcall %} {% call code('json') %}{"id": "file-EyVi0MrxuKTgBrvkVas5ZTGz", "object": "file", "bytes": 13264, "created_at": 1767210968, "filename": "contract.pdf", "purpose": "user_data"}{% endcall %} {{ ep('GET','/files?purpose=user_data&limit=100&order=desc') }}

فهرست فایل‌های حساب شما.

{{ ep('GET','/files/{file_id}') }}{{ ep('GET','/files/{file_id}/content') }}{{ ep('DELETE','/files/{file_id}') }} {% call code('python') %}f = client.files.create(file=open("contract.pdf", "rb"), purpose="user_data") r = client.responses.create(model="gpt-5.4", input=[{"role": "user", "content": [ {"type": "input_file", "file_id": f.id}, {"type": "input_text", "text": "مهم‌ترین بندها را فهرست کن"}]}]) print(r.output_text) client.files.delete(f.id){% endcall %}

تشخیص متن (OCR)

{{ ep('POST','/ocr') }}

استخراج ساختاریافته متن، جدول و تصاویر از PDF و تصویر با mistral-ocr-4-0 (۱۷۰ زبان، خروجی Markdown). هزینه بر اساس تعداد صفحه: حدود {{ ocr_price|int|fa }} تومان برای هر صفحه (با حاشیه‌نویسی ساختاریافته ۲٫۲۵ برابر).

  • document (الزامی): {"type": "document_url", "document_url": "https://... یا data:application/pdf;base64,..."} یا {"type": "image_url", "image_url": "..."}
  • اختیاری: pages (آرایه شماره صفحه از ۰)، include_image_base64، image_limit، image_min_size، table_format (markdown/html)، extract_header، extract_footer، document_annotation_format و bbox_annotation_format (خروجی JSON Schema).
{% call code('bash') %}curl {{ B }}/ocr \ -H "Authorization: Bearer lsk-YOUR_KEY" -H "Content-Type: application/json" \ -d '{"model": "mistral-ocr-4-0", "document": {"type": "document_url", "document_url": "https://arxiv.org/pdf/2201.04234"}, "pages": [0, 1], "table_format": "html"}'{% endcall %} {% call code('json') %}{ "pages": [{"index": 0, "markdown": "# عنوان سند\n\nمتن استخراج‌شده...", "dimensions": {"dpi": 200, "height": 2200, "width": 1700}, "images": []}], "model": "mistral-ocr-4-0", "usage_info": {"pages_processed": 2, "doc_size_bytes": 3002783}, "object": "ocr" }{% endcall %}

استخراج داده ساختاریافته از فاکتور

{% call code('json') %}{ "model": "mistral-ocr-4-0", "document": {"type": "document_url", "document_url": "https://example.com/invoice.pdf"}, "document_annotation_format": {"type": "json_schema", "json_schema": {"name": "invoice", "schema": { "type": "object", "required": ["invoice_number", "total_amount"], "properties": {"invoice_number": {"type": "string"}, "date": {"type": "string"}, "total_amount": {"type": "number"}}}}} }{% endcall %}

نتیجه ساختاریافته در فیلد document_annotation به‌صورت رشته JSON برمی‌گردد. پیش از ثبت مالی، مبلغ‌ها و تاریخ‌ها را با سند اصلی تطبیق دهید.

ویرایش تصویر

{{ ep('POST','/images/edits') }}

ویرایش تصویر موجود با توضیح متنی (حذف پس‌زمینه، افزودن شیء، تغییر سبک...). مدل‌ها و قیمت همانند تولید تصویر است (مدل‌های فعال در /models با نوع image).

آپلود فایل (multipart)

{% call code('bash') %}curl {{ B }}/images/edits \ -H "Authorization: Bearer lsk-YOUR_KEY" \ -F model="gpt-image-2" -F image="@product.png" \ -F prompt="فقط پس‌زمینه را سفید گرم کن؛ محصول، لوگو و زاویه دوربین تغییر نکند" \ -F size="1024x1024"{% endcall %}

درخواست JSON با Base64

{% call code('json') %}{ "model": "gpt-image-2", "prompt": "یک رنگین‌کمان در آسمان بالای کوه‌ها اضافه کن", "images": [{"image_url": "data:image/png;base64,iVBORw0KGgo..."}], "size": "1024x1024" }{% endcall %}

اختیاری: mask (فایل یا {"image_url": ...} با کانال آلفا؛ ناحیه شفاف قابل ویرایش است)، n (حداکثر ۴)، quality، output_format. خروجی در data[0].b64_json یا data[0].url است. در پرامپت کل تصویر نهایی را توصیف کنید و بگویید چه چیزهایی باید بدون تغییر بمانند.

استخراج فیلد (Extraction)

{{ ep('POST','/extraction') }}

متن یا تصویر را بخوانید و مقدارهای نام‌دار و نوع‌دار برگردانید (شناسه، تاریخ، مبلغ، فهرست، برآورد، پیش‌بینی) — همراه با نشانه‌های عدم قطعیت. مدل: cf.clairic. هزینه بر اساس توکن ورودی (بسیار کم). پاسخ جریانی پشتیبانی نمی‌شود.

  • state: متن شواهد (یا images: تا ۴ تصویر Base64 با content_type).
  • fields: شیء نام‌دار؛ نوع‌ها: text، number، date، time، datetime، duration، list (با items)، estimate و forecast (با min/max). تنظیمات: instructions، unit، decimals، null_threshold و ...
  • اختیاری: reference_date (برای تاریخ‌های بدون سال)، options.include_quantiles، options.return_state_text.
{% call code('bash') %}curl {{ B }}/extraction \ -H "Authorization: Bearer lsk-YOUR_KEY" -H "Content-Type: application/json" \ -d '{"model": "cf.clairic", "state": "Invoice INV-2291 issued 2026-09-02, net 30. 4 pallets at $250.00, shipping $80.00. Contact: Dana Ruiz, Priya Shah.", "fields": { "invoice_number": {"type": "text"}, "due_date": {"type": "date", "instructions": "Issue date plus net payment days"}, "total": {"type": "number", "decimals": 2, "unit": "USD", "instructions": "Amount due including shipping"}, "contacts": {"type": "list", "items": "text"}, "po_number": {"type": "text", "instructions": "Purchase order number"}}}'{% endcall %} {% call code('json') %}{ "model": "cf.clairic", "answers": { "invoice_number": {"type": "text", "value": "INV-2291", "confidence": 1, "p_null": 3.8e-10, "span": [8, 16]}, "due_date": {"type": "date", "value": "2026-10-02"}, "total": {"type": "number", "value": 1080}, "contacts": {"type": "list", "value": ["Dana Ruiz", "Priya Shah"]}, "po_number": {"type": "text", "value": null, "p_null": 1, "guess": "INV-2291"} }, "truncated": false, "usage": {"input_tokens": 655, "output_tokens": 0, "passes": 3} }{% endcall %}
⚠️ value: null یعنی مقدار پیدا نشد؛ guess را جایگزین آن نکنید (در مثال، شماره سفارش خرید وجود ندارد). پیش از ذخیره یا اقدام، مقدارها را اعتبارسنجی کنید.

گفتگوی صوتی زنده

برای ساخت دستیار صوتی، سه مرحله را زنجیره کنید: گفتار به متن ← چت ← متن به گفتار. این همان روشی است که «گفتگوی صوتی» سایت لمورا استفاده می‌کند.

{% call code('python') %}with open("question.webm", "rb") as audio: text = client.audio.transcriptions.create(model="gpt-4o-transcribe", file=audio, language="fa").text answer = client.chat.completions.create(model="gpt-5.4-mini", messages=[ {"role": "system", "content": "کوتاه و محاوره‌ای پاسخ بده."}, {"role": "user", "content": text}]).choices[0].message.content with client.audio.speech.with_streaming_response.create( model="gpt-audio-1.5", voice="coral", input=answer, response_format="mp3") as speech: speech.stream_to_file("answer.mp3"){% endcall %}
  • متن هر درخواست TTS را زیر ۴٬۰۰۰ کاراکتر نگه دارید؛ متن طولانی را پاراگراف به پاراگراف بفرستید.
  • صداهای پیشنهادی: coral، marin، cedar، alloy، nova.
  • برای کاهش تأخیر، پاسخ چت را کوتاه بخواهید و پخش را هم‌زمان با دریافت فایل شروع کنید.
  • به کاربر اطلاع دهید که صدای پاسخ با هوش مصنوعی تولید شده است.
