📖 شروع سریع

این API با کتابخانه رسمی OpenAI سازگار است. فقط base_url و api_key را تغییر دهید.

آدرس پایه: {{ api_base }}
from openai import OpenAI
client = OpenAI(base_url="{{ api_base }}", api_key="lsk-YOUR-KEY")
r = client.chat.completions.create(
    model="gpt-4o-mini",
    messages=[{"role":"user","content":"سلام!"}])
print(r.choices[0].message.content)
